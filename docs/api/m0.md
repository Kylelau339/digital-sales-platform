# M0 API 契约

## 健康与公开市场

```text
GET /health
GET /api/v1/templates
GET /api/v1/refund-policy
```

M0 市场返回真实数据库查询的空列表；不在 `USE_FIXTURES=false` 时回退到演示数据。

## 认证

```text
POST /api/v1/auth/register
POST /api/v1/auth/login
GET  /api/v1/auth/me
GET  /api/v1/auth/csrf
POST /api/v1/auth/csrf
POST /api/v1/auth/logout
```

注册/登录返回公开用户和内存态 CSRF token。浏览器 client 使用 `credentials: include`，不把 token 写入 localStorage。

写接口请求头：

```text
Origin: <exact configured origin>
X-CSRF-Token: <current session token>
```

缺失或错误返回 `CSRF_INVALID`。`GET /auth/csrf` 只允许已有有效 session，检查 cross-site fetch；它轮换当前 session token。

## M0 错误码

`AUTH_REQUIRED`, `FORBIDDEN`, `VALIDATION_FAILED`, `NOT_FOUND`, `CONFLICT`, `CSRF_INVALID`, `REFUND_WINDOW_EXPIRED`, `ENTITLEMENT_EXHAUSTED`, `ENTITLEMENT_REVOKED`, `ENTITLEMENT_EXPIRED`, `ENTITLEMENT_REISSUED`, `LICENSE_CONFLICT`, `SCAN_FAILED`, `SCAN_MANUAL_REVIEW`, `TEMPLATE_NOT_PURCHASABLE`, `INTERNAL_ERROR`。

每个错误响应都包含 `code`、用户可读 `message` 和 `requestId`。

## M0 明确不存在的路由

上传 finalize、扫描 job 执行、Stripe/USDT webhook、签名下载、管理员退款/下架和真实投诉处理路由留到后续里程碑；未知路由返回统一 `NOT_FOUND`，不会伪造成功。
